## Overview

This repository collects multiple experiments rather than one production application. The work explores script generation, captioning, image generation, narration, video assembly, a Flask service, and React or static web interfaces.

## My contribution

This repository includes experimental and starter-code based work. Each nested project should be reviewed independently before reuse, including its own licence and service requirements.

## What it does

| Area | Details |
| --- | --- |
| **Generation pipeline** | Scripts are broken into captions, images, narration, and assembled video. |
| **Model experiments** | Diffusion, transformer, image-generation, and voice-service integrations. |
| **Multiple interfaces** | React clients, a Flask backend, and static interface concepts. |
| **Output examples** | Saved audio, captions, preview media, and demonstration results. |

## Repository map

| Path | Purpose |
| --- | --- |
| `ALvideo/Simple_Ai_Video_Generator-main/` | Python pipeline for scripts, images, voice, and video assembly. |

| `ALvideo/web/` | Static interface and preview concept. |
